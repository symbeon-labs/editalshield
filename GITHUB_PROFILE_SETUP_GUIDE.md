# 📋 Guia de Setup - GitHub Profile README

## 🎯 Objetivo
Criar um perfil profissional no GitHub que destaque você como **founder thought leader** e arquiteto de sistemas de IA.

---

## 📝 Passo a Passo

### **1. Criar Repositório Especial**

No GitHub, crie um repositório com o **mesmo nome do seu username**:

1. Acesse: https://github.com/new
2. **Repository name:** `SH1W4` (exatamente igual ao seu username)
3. **Description:** `My GitHub Profile README`
4. **Visibility:** ✅ Public
5. **Initialize:** ✅ Add a README file
6. Clique em **"Create repository"**

> **Nota:** O GitHub detecta automaticamente quando você cria um repo com seu username e o trata como perfil especial.

---

### **2. Adicionar o Conteúdo**

Copie o conteúdo do arquivo `GITHUB_PROFILE_README.md` que criei para o README.md do repositório `SH1W4`:

**Opção A: Via Web (mais fácil)**
1. Acesse: https://github.com/SH1W4/SH1W4
2. Clique em **"Edit README.md"** (ícone de lápis)
3. Cole todo o conteúdo de `GITHUB_PROFILE_README.md`
4. Scroll até o final → **"Commit changes"**
5. Adicione mensagem: `feat: professional profile README`
6. Clique em **"Commit changes"**

**Opção B: Via Terminal**
```bash
# Clone o repositório
git clone https://github.com/SH1W4/SH1W4.git
cd SH1W4

# Copie o conteúdo
# (Abra GITHUB_PROFILE_README.md, copie tudo, e cole em README.md)

# Commit e push
git add README.md
git commit -m "feat: professional profile README with Symbeon Labs branding"
git push
```

---

### **3. Verificar o Resultado**

1. Acesse seu perfil: https://github.com/SH1W4

3. Verifique que:

## 🔧 Troubleshooting

### **README não aparece no perfil**
- ✅ Verifique que o repositório se chama exatamente `SH1W4`
- ✅ Verifique que o repositório é **público**
- ✅ Verifique que o arquivo se chama `README.md` (case-sensitive)

### **GitHub Stats não carregam**
- ⏳ Aguarde alguns minutos (pode demorar)
- 🔄 Force refresh: Ctrl+Shift+R (Windows) ou Cmd+Shift+R (Mac)

### **Badges quebradas**
- 🔗 Verifique os links das badges
- 🌐 Teste se as URLs estão acessíveis
